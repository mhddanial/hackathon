# SmartFlow AI

SmartFlow AI is a revolutionary logistics intelligence platform designed to optimize cross-border shipping routes in Southeast Asia, specifically focusing on the Batam-Singapore corridor.

## 🚀 Features (Frontend UI Phase Completed)
- **Route Intelligence (Home)**: Calculate speed, cost, and emission impact.
- **Logistics Overview (Dashboard)**: Real-time network performance, heatmap, and activity history.
- **Sustainability Impact (Smart Agent)**: Track CO2e savings, green fleet score, and eco-partner directories.
- **Ferry Schedules**: Live schedules with capacity and delay indicators.

## 💻 Tech Stack (Frontend)
- **Framework**: Next.js 14 (App Router), React, TypeScript
- **Styling**: Tailwind CSS, Shadcn UI
- **Icons**: Lucide React
- **Design Philosophy**: Premium Clean UI, Interactive Dashboards
